# 2.0.2 更新报告

发布日期：2026-11-26  
适用宿主：Folia 0.8.x

## 这版主要解决什么

2.0.2 把分 P、歌词、封面、音质和宿主页签的几处问题收拢到一起。它的重点不是新增一套界面，而是让 bilibili 这个音源在 Folia 现有的搜索、书库、探索、播放器和歌词面板里表现得更一致。

## 安装

1. 从 Releases 下载 `bilibili-2.0.2.zip`。
2. **完全退出 Folia**，只关窗口不算。
3. 解压到 `%APPDATA%\Folia\mods\bilibili\`，`mod.json` 要在这一层。
4. 启动 Folia，在「设置 → 模组 → 模组管理」打开 bilibili，确认信任后加载。
5. 书库首页 → 音源 → bilibili → 扫码登录。

从 2.0.1 升级时覆盖旧目录里的文件，登录凭据和设置会保留；确认信任后按提示重启。

## 用户能感觉到的变化

### 分 P 视频

- 搜索、收藏夹、合集里的多 P 视频会按 P 拆成独立歌曲。
- P1 保持原来的 bvid；P2 起用 `bvid#页码`。这样歌词缓存、历史、喜欢态和播放地址都能对到具体分 P。
- 标题会带 `· P2 分P名`，每 P 显示自己的时长。
- 探索页仍然一个视频只显示一张卡，只取 P1，不会被几十个 P 冲满。
- 翻页时不再把同一视频的后续 P 当成下一页视频跳过。之前一个 59P 视频第一页只给 P1–P20、第二页从下一个视频开始的问题已经修好。
- 「我喜欢的音乐」的心形状态会认到 `bvid#N`，P2 也能显示已喜欢。
- 有些视频的详情不返回分 P 列表。这版会再读一次分 P 清单，把分 P 补齐；少数仍然拿不到的视频会保留为整段视频。

### 歌词

- 「匹配歌词」面板里能看到 bilibili 页签，选中视频后取的是这个视频的 CC 字幕，不会混进其他平台的翻译和罗马音。
- 歌词搜索结果的封面补回来了；结果行和右侧预览不再空白。
- 选中 P2 时取 P2 的 CC 字幕，选中 P3 时取 P3 的，不再统一取 P1。
- 歌词源改为只走 Folia 0.8.x 的注册方式。旧宿主用的全局补丁已移除，避免影响别的模组。

### 登录和账号

- 未登录时，音源列表里的 bilibili 仍可点击，会打开 Folia 统一的扫码登录面板。
- 账号信息里会带会员状态。账号名旁出现会员图标时，表示当前 bilibili 账号是大会员。
- 登录状态读取失败时，只有 bilibili 明确回答「未登录」才算掉号；限流或网络抖动会沿用上次身份。

### 收藏夹封面

- 登录成功后不再一次补完所有收藏夹封面。单次最多补 12 个，剩下的在浏览时慢慢补。
- 被 bilibili 限流时会停一轮，等 5 分钟再继续，不再短时间反复打接口。
- 已有封面不会重复抓；空白封面会逐步填回来。

### 音质

- 音质档位改成四档：流畅、标准、高、无损。
- 宿主通名会换成 bilibili 实际音频流名称：64K、132K、192K、320K、FLAC、Hi-Res、杜比。
- 「高」显示 132K，「超高」显示 192K；「无损」优先真实 FLAC / Hi-Res，没有时再退回杜比或高码率。
- 不再把「无损」和「Hi-Res」当两条不同流展示，避免选了两档却听到同一条。

### 页签和探索

- 页签改名和「推荐」胶囊隐藏共用同一套判断，选中 bilibili 时才改；切到别的音源会还原。
- 新装 profile、shadow root、搜索页音源切换这些场景都按同一信号判断，减少改名串台。
- 探索页换一批仍避开最近听过的视频；首页推荐不会展开分 P。

## 升级提示

- 从 2.0.1 升级不需要重新扫码，登录凭据和设置会保留。
- 安装后仍要确认信任；升级包内容摘要变了，Folia 有时会要求重启。
- 首次进入书库时，封面可能不是一次全齐，滚动或重新进入收藏夹会继续补。
- 如果歌词面板暂时没有 bilibili 页签，完全退出 Folia 再打开一次。

## 验证情况

- 本地测试：261 通过，0 失败，3 跳过。
- 清单检查通过。
- 真机确认过分 P 翻页、歌词页签、歌词取词、封面、会员状态和页签适配。
- 新加的分 P 清单兜底有回归测试，覆盖详情不返回分 P、但分 P 清单可用的情况。
