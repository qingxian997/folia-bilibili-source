# 07 · 设置面板（`settingsPanel.mjs`，1124 行）

## 职责

设置面板本体：四个分组、说明折叠、收藏夹 / 合集选择器、额外列表、扫码登录、维护区。
从 `client.mjs` 搬出来的一整块（约 900 行），行为没改。

**它只认 `deps` 传进来的东西，不碰 client 的内部状态。** 要读缓存、要重画墙、
要升级登录态，都由 `client.mjs` 包一层薄函数再交进来。这样面板能单独改、单独测。

## 四个分组（默认全部折起）

```text
账号          扫码登录 / 退出 / 当前账号
内容          likedFolder 最上、收藏夹表、合集表、额外列表
播放与歌词    lyrics、route
高级          rawTitle 最上、maxMinutes、维护（清缓存 / 检查更新）
```

子表再折叠一层，摘要显示「共 N 个 · 显示 M 个」。折叠状态存在模块级 `ui` 对象里，
不写进设置值 —— 那是纯界面状态，换设备不该跟着走。

## 为什么不用宿主声明式表单

宿主的 `settings` 表单只有单行文本和静态选项，这里需要两样它没有的：

1. 多行的「额外列表」输入
2. 从账号里现读的「喜欢收藏夹」下拉

所以面板整个是自绘的，塞进宿主给的 ShadowRoot 容器（宿主加了 `all: initial`），
颜色必须自己定，按主题日夜挑一套，并跟着 `ctx.onChange` 换。

## 设置字段的类型限制

`mod.json` 的 `settings` 字段 `type` 只认：

```text
number | text | boolean | select | color | secret
```

界面形态放自定义键 `ui`，`type` 写 `text`。`secret` 是**加密存储的唯一入口**，
Cookie 必须走它，不能落到普通数据文件。

## 已知坑

- 面板在 ShadowRoot 里，`document.querySelector` 找不到面板内部节点，
  必须从 `container.querySelector` 起。
- 行内「?」按钮要贴右：`.bf-label { flex: 1 1 auto }`。
- 改设置值走 `paramStore.setValues / replaceAll`，有 250ms 防抖；
  测试里验证完要还原，否则会污染下一次用例。
- 隐藏的输入框不要 `display:none`，宿主的焦点管理会报错，用 `visually-hidden`。
